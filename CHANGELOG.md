## [1.1.0] - 2026-08-16 

### Updated
- Adapted code repository to new website tempalte
- Update to Vue3. 
- Migrate to new domain at water.usgs.gov/vizlab. 
- Fire perimeter timeseries data were updated to include data through 2025. Since the last build the published data source has changed. We now show fire perimeter data from Monitoring Trends in Burn Severity (MTBS https://mtbs.gov/) for 1984–2023, and from the interagency WFIGS perimeter feed (https://data-nifc.opendata.arcgis.com/datasets/nifc::wfigs-interagency-fire-perimeters/explore) for 2024–2025, whose seasons MTBS is still mapping. Includes wildfires of 1,000 acres or more; prescribed burns are excluded.
